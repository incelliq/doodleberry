# Brief — "What happens if a fly lays its eggs in your cut?" (3D)

First 3D short on the engine: a second-person "what happens if…" fact short about the New World screwworm, built for a
US audience (the fly is back in Texas, New Mexico and Arizona in 2026).

| field | value |
|-------|-------|
| length | ~55 s, 9:16, 30 fps |
| renderer | three.js r160 in headless Chromium (software WebGL2), `tools/three/run3d.mjs`; 2D SVG overlay for captions and cards |
| cast | Quaternius Universal Base Characters (CC0) male body + parted hair, eyebrows, beard; animation from Quaternius UAL (CC0) |
| props | all built in code: the screwworm fly (metallic blue-green, orange eyes, thorax stripes), sterile fly (grey, yellow band), egg mass, maggots, tweezers, bandage, plane, release boxes, lakeshore set, ranchland, the map board (our Natural Earth map drawn onto a texture) |
| beats | hook on a lakeshore scrape → fly lands → eggs (up to 500) → x-ray: maggots burrow, screw deeper when disturbed → rare in people: Nicaragua 30 cases (BMJ 2025), first US human case Aug 2025 → doctor removes larvae, cover open wounds (CDC) → 71 US cases by late Oct 2026 → planes drop sterile flies → mates once, sterile mate = no hatch → beaten in 1966, doing it again |
| facts | `facts.json` (13), every line traced |
